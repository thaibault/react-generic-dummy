react-generic-dummy 0.0.143

Project Status

Use case

A React component which renders nothing but its children inside a "div". It serves as stand-in for optional dependencies: Let your bundler resolve a package you do not want to ship to this component instead. Your code keeps compiling and can find out at runtime that the real component is missing via the flag "isDummy".

Content

Installation

npm install react-generic-dummy react

Example

Replace an optional animation library with the dummy in your webpack configuration:

export default {
    resolve: {
        alias: {
            'react-useanimations$': 'react-generic-dummy',
            'react-useanimations/lib/plusToX$': 'react-generic-dummy'
        }
    }
}

Check for the flag before using the component:

import type Dummy from 'react-generic-dummy'
import UseAnimations from 'react-useanimations'
import plusToX from 'react-useanimations/lib/plusToX'

export const Icon = () =>
    (UseAnimations as Partial<typeof Dummy>).isDummy ?
        <span>+</span> :
        <UseAnimations animation={plusToX} />

In tests the exported object "reference" holds the last reference passed to the dummy, so you can check what a component forwards to its child.
